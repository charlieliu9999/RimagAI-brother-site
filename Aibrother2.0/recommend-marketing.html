🌟 Icdss 适宜性标准与多模型引擎

i-CDSS 临床智能推荐系统
使影像检查开单更精准、更合规

基于2.2 万行临床适宜性标准知识库（Icdss）与大模型语义向量检索（RAG），结合四阶段规则拦截控制引擎。在开单环节实现实时临床决策支持，规避医保拒付并降低不合理检查率。

Solutions

两大核心业务应用方案

打通门诊实时开单与事后质量审计，全方位约束检查合理性

🩺

事中实时推荐与拦截（门急诊/住院）

深度嵌入 HIS 和电子病历系统。当临床医生下达检查医嘱时，系统在 2.5 秒内完成主诉向量检索和多模型推理，实时弹出适宜检查建议。对违反红线禁忌（如孕妇放射性检查）直接强制拦截。

实时阻断与提示 Icdss适宜度评分 SSE流式输出
📋

事后处方合理性审计（离线分析）

对已归档的历史处方进行全量批量审计。从医保控费、适应证匹配度、解剖侧别等多个维度计算临床开单合规率，导出科室及医师检查合理性分析白皮书，实现精细化临床绩效评价。

离线大批量审计 多阶段归因诊断 医师合规力排行榜
Rule Engine

四阶段规则引擎精准管控

结合权威临床决策指南，打造逻辑无懈可击的安全红线防护网

01

前置条件过滤 (pre_filter)

自动校验患者基础属性禁忌。例如，根据年龄、性别（如非生育期女性、孕妇）自动过滤掉带有电离辐射的检查类型。

02

适应证加权 (boost)

深度提取主诉中的特征词（如特定阳性体征、病史），对指南明确推荐的检查项目进行权重加成，优先推荐。

03

不合理抑制 (suppress)

针对低适宜度、短期内重复做同类型检查或医保不予报销的多余检查进行自动分数调减，抑制医生过度开单。

04

后置合规性校验 (post_validate)

校对推荐项目的解剖方位。例如，检测到开单部位侧别（如“右侧”）与临床主诉部位（如“左膝疼痛”）发生偏差时报错。

Recommendation Workflow

智能开单推荐引擎工作流

“NLP + 向量检索 + LLM”多阶段融合，实现极低误判与毫秒级决策反馈

01

主诉及临床体征语义解析

系统截取医生输入的诊断与病历，使用专业医学 NLP 模块提取核心病因、定位器官、发病时长和阳性体征。

02

Icdss 知识库语义向量匹配 (RAG)

提取出的核心特征经向量化，在 Milvus 数据库中进行多维相似度检索，秒级匹配最相关的 Icdss 适宜性评价标准和循证条款。

03

本地推理引擎推理与循证理由生成

调用经过医学领域增强训练的本地推理引擎，将检索出的 Icdss 指南融合患者当前体征，推理出 3 个最佳备选项目并生成简化推荐理由。

04

四阶段规则引擎实时干预过滤

将 LLM 推理结果输入规则过滤器，最终执行前置/后置禁忌抑制规则，通过 SSE 流式动态展现给开单医生，随开随算。

Doctor Client Experience

医生端无感集成与实时推荐

智能病历解析、一键采纳、合规防护，临床医生的开单“决策助手”

智能开单客户端

主诉秒级识别，推荐一键确认

i-CDSS 推荐端点通过轻量化接口无感集成至临床医生 HIS/EMR 书写流中。当医生在输入诊断或主诉病历时，系统在后台实现静默检索和推理。推荐面板随开随算，点击“采纳”，即可自动生成合规、适宜的影像检查医嘱，并填入理由，大幅减少开单的沟通和确认耗时。

  • 无感知毫秒级反馈：病历录入同时静默计算，2.5s 内返回最佳适宜性推荐。
  • 检查项目一键确认：拒绝繁杂的多级目录翻找，最佳影像检查即点即填。
  • 医保防拒付机制：前置排除不合理过度检查及禁忌症项目，从源头消灭开单拒付。
AI Agent Evaluation

自主基准评测与规则审计模块

基于自动化基准测试分析套件，全天候诊断推荐算法的微小缺陷

自主评测 Agent

内置 5 大工具，自主归因分析

i-CDSS 特别配备了基于 Tool-Use 模式的自动评测引擎。在每次大批量基准评测任务完成后，评测工具能够自动调度 5 大内置分析工具：从宏观 KPI 任务摘要、失败案例具体归因，到适宜性质量分布、跨任务多维度对比以及复杂错误模式分类，输出高度可读的 Markdown 诊断报告，甚至支持多轮人机交互追问。

  • 自动追溯与归因：针对推荐出错或评分低案例，自动定位是 RAG 知识缺失还是大模型幻觉。
  • MD5 原始数据防篡改：评测报告与 PostgreSQL 数据库数据一致性通过 MD5 校验和实时追溯。
  • 跨模型并发比对：支持不同大模型（如 Qwen 与 GPT-4）对同批临床案例的推荐合理性 KPI 跨任务对比。
Consensus & Learning

文献共识库管理与向量自同步

打破知识壁垒，将临床指南最新研究快速转化为推荐依据

i-CDSS 特别集成了独立运行的共识文献子系统 (Paper Management)。在主平台通过高性能 Nginx 代理与 Iframe 无缝整合，通过以下闭环确保知识库处于医学最前沿：

  • 医学文献/临床指南结构化提取
    后台提取 PDF 及权威医学文献，借助专有 LLM 抽取出包含“患者体征-首选检查-推荐级别”的标准结构。
  • 多级文献审核与版本控制
    支持医学部专家在前端通过“文献管理”模块对提取出的结构化条款进行人工审核校对与定稿。
  • Milvus 向量库一键自同步
    定稿文献一键启动后台同步，瞬间更新 Milvus 数据库中的向量特征，实时更新临床开单的检索基准。

Deployment

高弹性、低延迟的部署方案

满足三甲医院本地数据安全限制与集团云端弹性扩展的多样化诉求

医院内网部署 (On-Premise)

本地离线，零泄露风险

针对对患者隐私有严苛监管的三甲医院或区域影像中心。系统数据底座与推理模型完全部署在院内内网 GPU 节点中，支持离线运行。

  • 数据不出院：Milvus、PostgreSQL 等核心数据库均安装在内网，不与外网通信。
  • 模型本地推理：采用 Xinference 在本地 GPU 显卡中对开源大模型（如 Qwen2-7B-Instruct）进行高性能私有推理。
  • 极速局域网对接：HIS/EMR 接口通过内网 API 极速调用，平均响应时间压缩至 1.8 秒。
集团云端服务部署 (Cloud SaaS)

多机构弹性，集中管控

针对联体医院、集团医疗机构或互联网医院。数据托管于安全专有云，多分支机构一键快速接入，低建设维护成本。

  • API Provider Pool 容灾：支持配置多个大模型提供商（如 OpenAI、Ollama 等），当某个端点异常时自动熔断和故障切换。
  • Redis 高效缓存：对常规症状匹配的适宜性结果进行 Redis 高并发缓存，海量请求无延迟瞬时响应。
  • 统一版本升级：最新的 Icdss 规则集及模型微调在云端一键完成，所有接入分支机构即刻共享。
