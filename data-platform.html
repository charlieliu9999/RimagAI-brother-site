核心能力

不只是 Text-to-SQL，而是完整的数据访问治理方案

🗣️ 自然语言查询

支持中文自然语言提问，自动理解业务语义（如"上月骨科手术量"），无需了解数据库表结构和 SQL 语法。

🔧 MCP 工具链

基于 MCP 协议的工具编排，AI 可调用 SQL 查询、数据聚合、图表生成等工具，复杂分析任务自动拆解执行。

📋 Schema 感知

自动获取数据库表结构和字段说明，结合业务知识库理解字段含义，生成准确的查询语句。

📈 智能可视化

查询结果自动选择最佳展示方式：表格、柱状图、折线图、饼图。支持导出和分享。

安全与治理

医疗数据安全是底线，每次查询都在治理框架内执行

🛡️

权限矩阵

基于角色的数据访问控制。不同科室、不同职级看到不同范围的数据，细粒度到表和字段级别。

📝

审计日志

每次查询完整记录：谁、何时、查了什么、返回了什么。支持事后审计和异常行为检测。

🚫

SQL 安全沙箱

生成的 SQL 经过安全检查：禁止 DELETE/UPDATE/DROP，限制返回行数，参数化防注入。只读查询，零风险。

典型场景

信息科日常高频需求，现在一句话搞定

📊

运营数据查询

"本月各科室门诊量对比上月变化" — 自动关联挂号表和科室表，生成对比图表。

💊

药品用量分析

"近三个月抗生素使用量 TOP10 科室" — 关联处方表和药品目录，按科室聚合排序。

🏥

床位周转统计

"ICU 本周平均住院日和床位利用率" — 计算入出院时间差，统计占床率。

⚠️

质量指标监控

"本月非计划再入院率超标的病区" — 关联出院和再入院记录，按 30 天窗口计算。

💰

费用异常检测

"本月单次住院费用超过 DRG 标准 150% 的病例" — 关联费用表和 DRG 分组标准。
